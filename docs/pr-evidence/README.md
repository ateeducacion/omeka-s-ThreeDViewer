# Viewer interaction screenshots

These screenshots document the 3DH Lab's AGBS Omeka S theme pilot that motivated this module feature. They show the normal object-page viewer, the compact help panel, and fullscreen viewing. The module patch implements the same interaction in the GLB/glTF renderer; these screenshots are pilot evidence rather than a claim that the patch is installed in the pictured Omeka instance.

The 3D model was produced by the 3DH Lab. The professional JSTOR photograph is excluded from these screenshots.
